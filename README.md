## 1. 보완할 점

### 1.1 WebView 가시성 부족

현재 WebView 화면에서 지도와 조이스틱의 크기가 작고 여백이 많아 대시보드의 가시성이 떨어진다.

### 1.2 현재 위치 파악 어려움

RC카의 움직임은 비교적 정확하게 표현되지만, 현재 RC카가 어느 위치에 있는지 구체적인 확인이 어렵다.

### 1.3 이동거리 표시 부족

RC카가 얼마나 이동했는지 확인할 수 있는 실제 이동거리 정보가 제공되지 않는다.

### 1.4 조이스틱 제어의 한계

조이스틱 방식을 활용하여, 정밀한 제어가 어렵고 일정한 경로를 따라 움직이기 어렵다.

## 2. 보완 계획

### 2.1 WebView 가시성 개선

WebView 화면의 여백을 줄이고 주요 기능의 크기를 확대한다.
실시간 카메라 화면과 상태창을 추가하여 RC카의 주행 상태를 쉽게 확인할 수 있도록 한다.

추가할 상태 정보는 다음과 같다.

* 실시간 카메라 화면
* 현재 이동거리
* 배터리 상태
* RC카 현재 상태
* 센서 데이터 표시

### 2.2 조이스틱 제어에서 자율 주행으로 전환

기존 조이스틱 기반 수동 제어 방식에서 자율 주행 방식으로 전환한다.
직접 조작 없이도 정해진 경로를 따라 이동할 수 있도록 개선한다.

### 2.3 오도메트리 기능 구현

6축 센서, 모터 데이터, 카메라 정보를 활용하여 RC카의 위치와 이동거리를 추정하는 오도메트리 기능을 구현한다.

활용할 데이터는 다음과 같다.

* 6축 센서 데이터
* 모터 회전 정보
* 카메라 영상 정보
* 앞바퀴 조향각
* 주행 시간
